# Robotic Pick-and-Place Sorting Cell: preliminary design package (Rev B)

This package recreates the 6-axis desktop robot from the reference video: planetary joint gearboxes, a parallel-linkage gripper, a pedestal and the pick and place fixtures (**Package A**). It also includes the extras from the brief that are not in the video: a belt conveyor, a linear 7th axis, sorting bins and guarding (**Package B**). Everything is generated from one parametric Python model (`00_SOURCE`), so every file in the package agrees with every other.

## Quick start in SOLIDWORKS

Follow `00_SOURCE/SW_MACROS/README_RUN_IN_SOLIDWORKS.md`: import the 11 `.bas` modules into a new macro saved in that folder, then run `BuildEverything`. Send back `11_BOM_AND_DOCUMENTATION/SW_BUILD_LOG.txt` if it reports warnings or errors.

## Key figures

Reach is 467 mm. There are 6 axes plus a gripper. There are 7 NEMA 17 motors, with a 6:1 planetary gearbox at J2–J6 and a 6:1 ring gear at J1. The gripper opens from 4.4 to 40 mm. Package A runs a 12 s cycle and Package B a 14 s cycle. The printed parts weigh about 2.7 kg (A) and 0.6 kg (B).
